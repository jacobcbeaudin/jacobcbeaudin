The next three, building ML infrastructure for a billion-dollar marketplace: the data layer models learn from, the training platform itself, and now AI agents. I work both sides: the models that ship, and the platform under them. And I like platforms best when they run without me.

## Now

- **At work:** evaluation and data-quality infrastructure for marketplace ML (pricing, curation, fraud, personalization), and an agentic harness for the development lifecycle: the gates an agent clears before its work ships, the runbooks it can execute, and the telemetry that proves what it did.
- **Upstream:** [fixes](https://github.com/marimo-team/marimo/pulls?q=is%3Apr+author%3Ajacobcbeaudin) and [root-caused issues](https://github.com/marimo-team/marimo/issues?q=author%3Ajacobcbeaudin) to marimo, the notebook my platform work runs on.
- **On my own time:** a notebook server in Rust, verified against marimo by differential tests. Demo on request.
